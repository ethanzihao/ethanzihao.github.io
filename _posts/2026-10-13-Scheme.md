# define

`(define A B)` is to bind A to B, where A and B are **totally equivalent** .
e.g.
```scheme
(define (square x) (* x x))
```
This binds `(square x)` to `(* x x)` . *Because `(* x x)` is a function call, so former one must also be a function call, then include `()`*

```scheme
(define square (lambda (x) (* x x)))
```
This binds `square` to `(lambda (x) (* x x))` . Because `lambda` aways returns a name, so `square` must be a name, then no `()` included. 
# lambda

```scheme
(lambda (parameter) statment)
```
No need to give `statement` a `()` . 
# `cond` 

```scheme
(cond (condition1 conclusion)
      (condition2 conclusion)
      (else conclusion))
```
**DO NOT** forget `()` out of each statements
